## 11:05 — Pivot: discovered free bulk ClaimReview feed

While checking quota docs, found Data Commons live feed: `https://storage.googleapis.com/datacommons-feeds/claimreview/latest/data.json` — 189MB, ~92.7k entries, ClaimReview schema, updated hourly, CC-BY, no API key. Strict superset of API fields (includes `itemReviewed.appearance[].url` — cited source URLs — which the API does NOT expose).

Downloaded once to `eval/data/feed/data.json`. Analysis:

- Total entries: 92,742
- 60.2% have `appearance` (cited sources)
- Rating strings extremely heterogeneous across languages: "False" / "FALSE" / "Falso" / "نادرست" / "誤り" / "Pants on Fire" / "Misleading" / "Half True" / etc. Harmonisation will be required for any cross-publisher use.
- `inLanguage` is almost always unset — can't filter by language from the field; must infer from publisher domain or lang-detect on text.

**Monthly harvest request cost estimate**: ~9-16 API requests/month. Trivial.

**API limits**:
- No `query` parameter required if `reviewPublisherSiteFilter` set
- No date-range query — only `maxAgeDays` (from today). To get a specific past month, query `maxAgeDays=N` and post-filter.
- pageSize max effectively 100; no documented cap on total results, in practice some publishers return only a few hundred per year regardless of true volume.

**Ratings**: top distinct strings span "False / True / Fake / Misleading / Correct Attribution / Originated as Satire / Mixture / Miscaptioned / AI-generated / Mostly True / Incorrect / Mostly False / Half True / Pants on Fire / …" plus long-tail free-text. Harmonisation will be needed.
